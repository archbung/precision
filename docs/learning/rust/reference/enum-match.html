Enum → exhaustive match

An enum names a type with alternatives called variants. An enum value is one variant at a time. See the official enum chapter.

match self {
    Self::Repetitions => "repetitions",
    Self::Duration => "duration",
    Self::Distance => "distance",
}

Within impl Measurement, Self names Measurement. Read an arm as “if this pattern matches, evaluate this expression.” The matching expression supplies the value of the whole match. Every possible input must be covered. See the official match chapter.

Explicit variant arms make a newly added variant require a decision here. A wildcard _ covers remaining cases, which may or may not be desirable for a particular contract. Exhaustiveness checks coverage; it does not prove the chosen string is correct.

This is a syntax reference, not a record of learner mastery. Borrowed string types, traits, and errors are reserved for later lessons.
